
# CampusConnect

CampusConnect is a college club membership and event management system built using Python and Streamlit.

## Features
- Dashboard
- Student Management
- Club Management
- Membership Registration
- Event Management
- Set Operations

## Technologies Used
- Python
- Streamlit
- Pandas

## How to Run

Install the packages:

    python -m pip install -r requirements.txt

Run the application:

    python -m streamlit run app.py
